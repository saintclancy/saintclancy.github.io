# ClancyLand

Personal portfolio site for Clancy Long, published at [clancy.land](https://clancy.land/).

## Project Shape

- `index.html` contains the page structure and content.
- `style.css` contains the custom presentation.
- `assets/scripts/script.js` contains tab, portfolio filter, and music-player behavior.
- Local images, video, and music live under `assets/`.

## Local Preview

This is a static GitHub Pages site with no build step or package manager. Open `index.html` directly in a browser, or serve the repository with a local static server:

```powershell
python -m http.server 8000
```

Then visit <http://localhost:8000>.
